# PhoneBooks — бухгалтерия скупки смартфонов

Веб-приложение для небольшой скупки и продажи телефонов: склад, касса и счета, расходы, переводы, аксессуары, прибыль по каждому телефону, история операций, резервные копии.

Приложение работает полностью в браузере (PWA). **Сервера и базы данных нет — данные хранятся на вашем устройстве** (IndexedDB), в интернет ничего не отправляется.

Публичная ссылка после публикации: `https://bikmako.github.io/phonebooks/`

## Как опубликовать на GitHub Pages

1. Откройте репозиторий `bikmako/phonebooks` на github.com.
2. Нажмите **Add file → Upload files** и перетащите **всё содержимое** этой папки (включая скрытый файл `.nojekyll` и папки `assets`, `icons`, `fonts`). `index.html` должен лежать в корне репозитория. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты вверху страницы Pages появится зелёная плашка со ссылкой на сайт. Репозиторий должен быть публичным (на бесплатном тарифе Pages работает только так).

## Установка на телефон и компьютер

- **iPhone (Safari):** «Поделиться» → «На экран Домой».
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **Windows (Chrome / Edge):** значок установки в адресной строке.

## Хранение данных — важно

- Данные лежат в браузере конкретного устройства. **Телефон и компьютер не синхронизируются.**
- Данные привязаны к адресу сайта и к браузеру. Очистка данных сайта, режим инкогнито или смена браузера стирают их. Safari на iPhone может удалять данные сайтов, которыми давно не пользовались.
- **Делайте резервные копии:** Настройки → Резервные копии → «Скачать файл». Файл `phonebooks-ГГГГ-ММ-ДД.json` сохраните в надёжном месте (облако, почта себе). Восстановление — «Загрузить из файла».
- В приложении также есть до 10 точек восстановления внутри браузера, но они пропадут вместе с данными сайта — не заменяют скачанный файл.
- Чтобы перенести данные на другое устройство: скачайте файл на одном, загрузите на другом.

## Безопасность

- В репозитории нет паролей, токенов и ключей; приложение не обращается к внешним серверам.
- **Репозиторий публичный — никогда не загружайте в него файлы резервных копий (`phonebooks-*.json`) и любые данные клиентов.** Файл `.gitignore` защищает от случайного добавления при работе через Git.
- Сайт открыт всем, у кого есть ссылка, но данные каждого посетителя хранятся только в его браузере: чужих записей он не увидит, а ваши записи другие не увидят.

## Ограничения GitHub Pages

- Только статические файлы: нет входа по паролю, нет общей базы, нет совместной работы нескольких сотрудников в одной учётной записи.
- Если нужна общая база для нескольких людей или устройств с автосинхронизацией, потребуется серверная часть (например, Supabase или Firebase) — это отдельная доработка приложения.
- Другие бесплатные хостинги для такой же статической сборки: Cloudflare Pages, Netlify, Vercel — достаточно загрузить эту папку; при размещении не в подпапке `/phonebooks/` ничего менять не нужно, пути относительные.

## Состав

| Файл / папка | Назначение |
|---|---|
| `index.html` | Точка входа |
| `assets/` | Собранные JS и CSS |
| `fonts/`, `icons/`, `favicon-32.png` | Шрифты, иконки PWA, favicon |
| `manifest.webmanifest` | Манифест PWA |
| `sw.js` | Service Worker (офлайн-режим) |
| `404.html` | Переадресация неизвестных адресов в приложение |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

> Это готовая сборка приложения без исходных кодов. Если вы дорабатываете исходники отдельно (Vite), при сборке используйте `base: './'` или `'/phonebooks/'` и сохраните относительные пути в `sw.js` и `manifest.webmanifest`.
