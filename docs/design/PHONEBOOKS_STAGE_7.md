# PhoneBooks 2.0 — этап 7

Рабочие экраны Solo и Team используют общую навигацию, типографику, кнопки, статусы, карточки показателей, выбор периода и графики. Утверждённое изображение сохранено без изменения. [Референс](phonebooks-v2-approved.jpg)

## Экраны

- **Solo.** Обзор, скупка, аксессуары, локальный каталог с пользовательскими категориями, форма закупки со сканером IMEI, карточка устройства, продажи, ремонт, финансы, история и настройки. Каталог сохраняет карточки и характеристики в IndexedDB и входит в полную копию для переноса в Team.
- **Team.** Вход и восстановление пароля, выбор и создание рабочего пространства, обзор предприятия и личные показатели, склад, закупка, карточка товара, продажи, передача и завершение ремонта, финансы, история, сотрудники, приглашения, роли, индивидуальные права и сессии.
- **Team API.** Миграция `202611260011_phonebooks_product_operations.sql` добавляет передачу в ремонт и историю с фильтрацией по периоду, виду операции и товару. Передача использует ту же блокировку рабочего пространства, проверку версии и квитанции запросов, что действующие облачные операции. История выдаёт суммы, прибыль и названия счетов по разрешениям.

## Сравнение с референсом

В обоих режимах видны тёплый фон, чёрные основные действия, жёлтые диагонали и центральная кнопка мобильной навигации. Обзор использует компактные показатели и строки операций с тонкими разделителями. Карточки товара организованы вкладками. Финансовый раздел использует монохромные столбцы, отдельный баланс счетов и данные движения денег. При сравнении уплотнены карточка Team и мобильный склад, а даты операций Solo вынесены на вторую строку. Для товаров без фотографий используются иконки. Дополнительные поля форм, разрешения и состояние связи занимают собственные строки.

- IMEI — 4 сценария в Chromium и WebKit с реальным OCR на тестовом файле и проверкой освобождения камеры.
- Production-сборки Solo и Team собраны локально.

## Локальный запуск

```bash
npm ci
npm run dev
npm run build
npm run build:team
npm test
npx playwright install chromium firefox webkit
npm run test:team
```

`npm run dev` открывает Solo на `http://localhost:5173/`. Команда `npm run test:team` поднимает локальные стенды Team на `https://127.0.0.1:4398/` и Solo на `http://localhost:4397/`, создаёт отдельную тестовую БД и проверяет оба режима. Для тестового HTTPS требуется OpenSSL. Чтобы повторить снимки, задайте `PHONEBOOKS_STAGE7_SCREENSHOTS=docs/design/stage-7` и запустите `npm run test:team -- product.spec.js`.

## Границы приёмки

- Team ещё требует применения новой миграции вместе с обновлением приложения на стенде. Эта проверка выполнена локально.
- В Team пока нет рабочего проведения возврата или отмены продажи, плановой цены продажи, сканирования IMEI и редактирования названия предприятия. История выводит сохранённые операции, включая перенесённые отмены. Возврат, плановая цена и сканер доступны в соответствующих сценариях Solo.
- Локальный каталог других товаров в Solo хранит данные карточек. Закупки и продажи этих категорий с движением остатков проводятся в Team.
- Подписка отсутствует в этой ветке. Проверка интерфейса на физическом iPhone остаётся отдельным шагом.

Актуальная спецификация и новые снимки экранов авторизации доступны в [дизайне авторизации](PHONEBOOKS_AUTH.md).
