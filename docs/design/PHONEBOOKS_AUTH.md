# PhoneBooks 2.0 — авторизация

Утверждённая спецификация для входа, регистрации, подтверждения почты и восстановления пароля в PhoneBooks Team. Восстановление проходит через запрос письма, переход по ссылке и ввод нового пароля.

| Элемент | Параметры |
| --- | --- |
| Шрифт | Manrope с кириллицей, локальные WOFF2 |
| Логотип | 34 px, вес 800, жёлтая точка |
| Заголовок | 28 px, вес 700 |
| Названия полей | 13 px, вес 600 |
| Текст полей | 15 px, вес 400 |
| Основная кнопка | 15 px, вес 600 |
| Второстепенный текст | 13 px, вес 500 |
| Фон | `#F7F6F2` |
| Поля | `#FFFFFF` |
| Основной текст и кнопка | `#191919` |
| Акцент | `#EBD66B` |
| Контуры | `#DEDDD7` |
| Радиус полей и кнопок | 10 px |

Одна колонка шириной до 380 px центрируется по горизонтали и вертикали. На телефоне ширина ограничена доступным пространством. При недостаточной высоте экран прокручивается. При смене шага содержимое плавно появляется, если пользователь разрешил анимации. Во время запроса кнопка блокируется и показывает индикатор загрузки. Результаты и ошибки сообщаются текстом.

Manrope загружается с того же источника, что и приложение. Общая таблица шрифтов лежит в [fonts.css](../../src/product/fonts.css). Сборка Solo включает оба файла в офлайн-кеш PWA.

## Проверка

Прошли 83 модульных и интеграционных теста и 33 браузерных сценария в Chromium, Firefox и WebKit. После уточнения расположения второстепенных действий повторно прошли три проверки экранов авторизации. Сценарии охватывают ответ при неподтверждённой почте, ожидание сервера, сессии, восстановление пароля и ширину 320 px. В Solo проверена загрузка кириллицы и латиницы Manrope после перезагрузки без сети.
