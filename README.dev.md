# PhoneBooks — исходный проект (React + Vite)

Восстановленный редактируемый исходный проект приложения PhoneBooks — бухгалтерии
для бизнеса по скупке и продаже смартфонов. Логика, разметка, стили и схема данных
сохранены в соответствии с готовой сборкой, которая лежала в репозитории.

> **Старая готовая сборка сохранена нетронутой.** Её побайтовая копия лежит в
> `backup/original-build/`, а исходное состояние зафиксировано локальным тегом
> `original-build-v1`. Корневые `index.html`, `assets/`, `fonts/`, `icons/`,
> `sw.js`, `manifest.webmanifest`, `404.html`, `README.md` не изменялись.
> Точка входа исходного проекта — отдельный файл `app.html`.

## Требования

- Node.js 20+ (проект проверен на Node 22), npm.
- Современный браузер с IndexedDB и Service Worker.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/  — исходное приложение
```

Dev-сервер отдаёт `app.html` по адресу `/`. Для сравнения старая сборка доступна
по адресу `/backup/original-build/index.html`.

```bash
npm run build      # результат в dist/
npm run preview    # http://localhost:4173/ — проверка production-сборки
```

Сборка переименовывает `app.html` в `dist/index.html`, копирует `public/` и
**перегенерирует `dist/sw.js`**: список кешируемых файлов и версия кеша
(`phonebooks-v9-<hash>`) вычисляются из реального содержимого `dist/`, поэтому
офлайн-режим не ломается при смене хэшей ассетов.

## Публикация на GitHub Pages

1. `npm run build`.
2. Загрузить **содержимое `dist/`** в корень ветки `main` (или в `docs/` — тогда
   в настройках Pages выбрать соответствующую папку).
3. Settings → Pages → Deploy from a branch → `main` / `/(root)`.

`base: "./"` в `vite.config.js` означает относительные пути: сборка одинаково
работает в корне домена и в подпапке `/phonebooks/`. Манифест (`start_url
./#/dashboard`), иконки, шрифты и `sw.js` также используют относительные пути.

## Структура

```
app.html                 точка входа Vite (PWA-метатеги, splash, storage.persist)
vite.config.js           сборка, dev-точка входа, генерация Service Worker
src/
  main.jsx               монтирование React, тема до рендера, регистрация SW
  App.jsx                hash-роутинг, тосты, шторка быстрых действий
  pages/                 Главная, Скупка, Аксессуары, Продажи, Финансы, История, Настройки
  components/            базовый UI, графика, каркас, формы и модальные окна
  hooks/                 useStore (контекст состояния), тема оформления
  domain/                бизнес-логика: валидации, операции, расчёты, аудит
  utils/                 форматирование, расчёты, справочники, черновики, роутинг
  storage/               IndexedDB, бэкапы, экспорт/импорт, начальное состояние
  styles/app.css         исходный скомпилированный CSS (без изменений дизайна)
  fonts/                 Manrope (копии исходных шрифтов для сборщика стилей)
public/                  manifest, иконки, favicon, 404, .nojekyll, шаблон sw.js
backup/original-build/   эталонная копия готовой сборки
```

## Данные — важно

Приложение полностью локальное: **сервера, облака и авторизации нет**. Данные
хранятся в браузере и не отправляются в интернет.

| Что | Значение |
|---|---|
| База | IndexedDB `phonebooks`, версия `1` |
| Object stores | `state`, `backups` (`keyPath: id`), `meta` |
| Ключи | `state` → `current` (весь объект состояния), `meta` → `lastSaved` |
| Резервные копии | до 10 записей `{id, at, payload, phones, sales, reason}` |
| Журнал аудита | до 2000 записей в `data.audit` |
| localStorage | `phonebooks.data.v1` (миграция), `phonebooks.theme`, `phonebooks.draft.*`, `phonebooks.ping` |
| Файл экспорта | `phonebooks-ГГГГ-ММ-ДД.json`: `{app:"PhoneBooks", version, exportedAt, data}` |
| Стартовый счёт | `ac_default_cash` — «Касса», `openingBalance: 0` |

**Совместимость с уже сохранёнными данными:** имя/версия базы, object stores,
ключи, структура `data` (`schemaVersion: 1`), формат бэкапов и ключи localStorage
оставлены без изменений. Никаких миграций и сбросов не производится — данные,
созданные старой сборкой, открываются новым исходным проектом как есть.
Телефон и компьютер по-прежнему не синхронизируются: для переноса используйте
Настройки → Резервные копии → «Скачать файл» / «Загрузить из файла».

## Ограничения восстановления

Исходников и sourcemap-ов в репозитории не было: модули восстановлены из
минифицированного бандла. Названия файлов, функций и констант даны заново,
логика и разметка перенесены без изменений. Локальные имена переменных внутри
тел функций в ряде модулей остались короткими (как в бандле) — это не влияет
на работу, но при дальнейшей доработке их можно переименовывать постепенно.
Точные версии Vite/Tailwind/recharts в оригинале неизвестны; здесь используются
React 18.3.1, lucide-react 0.454.0, recharts 2.15.4, Vite 5.4.21.
Tailwind-конфиг не подключался: `src/styles/app.css` — дословно сохранённый
скомпилированный CSS готовой сборки.
